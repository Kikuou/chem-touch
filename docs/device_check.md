# 実機確認の手順書（iPhone・Android）

開発環境には実機がないため、指の操作・表示の速さ・端末の設定による違いは、実際のスマホで確かめる必要があります。授業で使う前に、少なくとも iPhone（Safari）と Android（Chrome）を1台ずつ、この順に確認してください。1回あたり20分ほどです。

結果は「端末名・OS の版・ブラウザ」と「できた／できなかった（どの番号で、何が起きたか）」をメモして、開発担当に伝えてください。画面の写真（スクリーンショット）があると助かります。

## 0. 準備
1. スマホで https://kikuou.github.io/chem-touch/ を開く
2. Wi-Fi につないだ状態で始める（9. でオフラインも確かめます）
3. iPhone は「設定 → 画面表示と明るさ」、Android は「設定 → ディスプレイ」で、ライト（明るい表示）になっていることを確認する（7. でダークも確かめます）

## 1. ホーム・今日の授業
- [ ] 「回をえらぶ」→ 第7回を選ぶと、いちばん上のカードが「第7回 炭素がつくる分子と官能基」になる
- [ ] 画面が横にずれない（左右にスクロールしない）
- [ ] 「身近なもの」の4つ、「基礎の復習」の横の並び（指で横に動かせる）、「道具」の4つが見える

## 2. 色カード
- [ ] 今日の授業のカードの「色カード」→ A〜D の4色が画面いっぱいに出る。下のタブは出ない
- [ ] B をタップ → 画面全体が青になり、大きく「B ▲」。もう一度タップで選び直し
- [ ] 画面を明るい教室で掲げて、離れたところ（教室の後ろ）から色と文字が見分けられる

## 3. 授業のページ・おわりの3問
- [ ] 第7回のページで「きょうの流れ」の各行をタップすると、それぞれの画面が開き、左上の「＜」で戻れる
- [ ] 「おわりの3問」を最後まで答えると結果が出て、「基礎の復習」の第7回に ✓ がつく

## 4. 分子・3D
- [ ] 「分子」タブ → 「アルコール」で一覧の絵がすぐ出る（数秒待たない）
- [ ] エタノールを開くと、3D が指1本で回り、2本指で拡大・縮小できる。ページ全体はずれない
- [ ] 構造式の原子をタップすると、3D の同じ原子が光る

## 5. なぞって描く（指の操作）
- [ ] 「つくる」→「なぞって描く」で、指でなぞると炭素の鎖が描ける。描いている間にページが上下に動かない
- [ ] 下の「−OH」を原子までドラッグすると −OH がつく。「戻す」で1つ前にもどる
- [ ] 線をタップすると 単結合 → 二重結合 → 単結合 と変わる
- [ ] 原子を長押しするとメニューが出る。2本指で拡大・移動できる
- [ ] 「ほか」を開いたまま、iPhone は画面の左端から右へスワイプ（戻る）、Android は戻るボタン → メニューが残らない

## 6. 触る教材・計算練習
- [ ] 「温度と三態」: スライダーを指で動かせる。−20 ℃ で氷、120 ℃ で水蒸気になり、分子がなめらかに動く（カクカクしない）
- [ ] 「組成式パズル」: イオンをタップして入れ、MgCl₂ ができる
- [ ] 「計算練習」: 画面のテンキーで数字が入る。スマホのキーボードは出ない
- [ ] 「なかまわけ」「反応式の天びん」「中和の滴定」が、指で操作できる

## 7. 端末の設定による違い
- [ ] ダーク（暗い表示）にして、ホーム・分子のページ・色カード・組成式パズルの文字が読める
- [ ] 文字を大きくする設定（iPhone: 設定 → 画面表示と明るさ → テキストサイズ、Android: 設定 → ディスプレイ → フォントサイズ）を最大にしても、ボタンの文字がはみ出して読めなくならない
- [ ] 視差効果を減らす（iPhone: 設定 → アクセシビリティ → 動作 → 視差効果を減らす、Android: 設定 → ユーザー補助 → アニメーションを削除）をオンにすると、「温度と三態」「ひきあう分子」の分子が止まった絵になる
- [ ] 画面を横向きにしても崩れない

## 8. QR コード
- [ ] 分子のページの右上の QR ボタンで QR が出る。別のスマホのカメラで読むと、同じページが開く
- [ ] ホームの QR ボタン（読み取り）で、カメラの許可を求められ、QR を読み取れる

## 9. オフライン
- [ ] ホーム・第7回のページ・エタノールのページを一度開いてから、機内モードにする
- [ ] アプリを開き直しても、その3つのページが表示される

## 10. ホーム画面に追加
- [ ] iPhone: 共有ボタン → 「ホーム画面に追加」。Android: メニュー → 「ホーム画面に追加」（または「アプリをインストール」）
- [ ] ホーム画面のアイコンから開くと、アドレスバーのない画面で開く

## 11. 先生の PC（プロジェクター）
- [ ] PC のブラウザで第7回のページを開き、P キーで提示モードにする。右上に QR が出たままになる
- [ ] 「くわしい表示」をオンにして「先生用：問題を映す」を開き、スペースキーで答えが出る、← → で問題が変わる
- [ ] 学生のスマホでその QR を読むと、第7回のページが開き、そのスマホのホームの「今日の授業」が第7回になる
