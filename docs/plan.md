## 1. 授業と学生

- 全学の共通教養科目「化学」（新設）。開講は約1年後（2026年11月時点）。
- 受講者は栄養・看護・経済などの学生で、化学を専門としない。1クラス最大 100 名、教室に Wi-Fi あり、操作は基本スマホ。
- ねらい: 高校化学の復習はするが、完璧にできることは求めない。**理屈・原理と実生活のつながりを知り、「化学は面白い、役に立つ」と感じてもらう**。
- 有機化学は主題ではない。身近な例として関心を引くために使う。栄養・看護に役立つ知識も入れる。
- 教科書は未定。用語は高校「化学基礎」の一般的な表記で作り、決まったら合わせる。
- **成績評価の機能は入れない。** 確認問題・計算練習は自分の学習用で、結果の提出・回収はしない。

## 5. 提案（合意済み）

### 第1段階で行うもの
1. **ホームを「今日の授業」「基礎の復習」「身近なもの」に。** 「身近なもの」は1つの入口で、開くと 食品／からだ／くすり・医療／くらし に分かれる。化学の分類は一覧の絞り込みとして残す。「くらし」は数件の化合物追加が必要（PubChem で照合）。
2. **分子ページを「ひとことで言うと」中心に。** 名前（読みがな）→ ひとこと解説 → 3D → 官能基 → 関連。専門データは「くわしいデータ」に折りたたむ。学科ごとの一言を足せる欄を用意する（中身は教員が書く）。
3. **作図は「なぞって描く」に一本化。** `#/build/draw2` を正式にし、古い「選んでから変える」を外す。書きかえ練習の「描く」も同じ画面にする。**「戻す」を部品の棚（「消す」の隣）に加える**（上部の元に戻す矢印は残す）。炭素鎖と上級エディタは「ほか」に残す。
4. **「くわしい表示」スイッチ**（「その他」に置き、初期はオフ）。オンのときだけ: 立体構造式、三重結合、SMILES 入力、上級エディタ、InChIKey などのデータ、傾向グラフ。

### 講義で使う機能
5. **今日の授業ページ／色カード／おわりの3問／提示モードの常設 QR。**
   - 色カード: 教員が問題を映す → 学生が A〜D をタップ → 画面全体がその色と文字になる → 掲げる。サーバーなし。色と文字の両方で示す。
   - 回答の集計はしない（色カードで足りる、と決定）。
6. **「たしかめる」タブ**に官能基クイズ・書きかえ練習・電子配置ビルダーをまとめる。できた印は端末内だけに保存。用語をタップすると説明が出る用語集（40語程度）。読みがなを全件に。

### 内容・保守
7. **解説文の確認を一覧表で一括に**（表計算ファイルで書き出し → 教員が直す → 一括反映）。
8. **動作と保守**: 構造式の画像をデータ生成時に作り、最初の表示を速くする（100人同時でも待たせない）。CSS の名前の衝突防止とホームの見た目の自動テスト。実機確認の手順書。

### 基礎の教材
9. **15回に合わせた「触って分かる教材」。**
   - 1教材＝1画面＝1つのこと。スライダーかドラッグ1つで結果がすぐ変わる。文章は2行まで。
   - 3つの型を作って中身をデータで差し替える: スライダー型（三態・モル・濃度・pH）、仕分け・並べ型（なかまわけ・組成式・反応式）、粒子アニメ型（三態・分子間力・自由電子・酸化還元）。
   - 端末の「視差効果を減らす」設定のときはアニメを止めて段階の図にする。
10. **計算練習（第8〜12回）。** 図で見当をつけてから数字を入れる。①4択 → ②穴うめ → ③自分で計算 の3段階（①だけで終えてよい）。入力はテンキーのみ、有効数字2桁程度の幅で正解。まちがえたら手順を1つずつ見せる。題材は身近なもの。
11. **シラバスを教員が組み替えられる構造。**
    - 教材カタログ: 分子・くらべる・触る教材・確認問題・計算練習を、回に属さない部品（ID つき）として持つ。
    - 授業プラン: 「第○回: 題名、身近な話題、使う部品の順」を書いた1つのファイル。年度ごとに持てる（複製して直す）。
    - ホームの「今日の授業」、「基礎の復習」の目次、各回のページ、おわりの3問は授業プランから自動で作る。
    - アプリ内の「授業をつくる」画面（教員用、「くわしい表示」の中）で、回の追加・部品の選択・並べ替えをし、書き出して GitHub に置く。
    - 今日の授業はその場で選び直せる（日付に縛られない）。部品にない話題は文章と画像のカードで足せる。

## 7. 作図（なぞって描く）の仕様メモ

- 1本指でなぞると炭素の鎖（長さで炭素数。指の上に C4 などと表示）。既存の原子からなぞるとそこから伸びる。
- 線をタップで単→二重→三重。原子をタップで C を1つ伸ばす。
- 部品の棚（並びは固定）: O・N・−OH・=O・−COOH・ベンゼン・消す（ここに「戻す」を加える）。原子までドラッグ、または押してから原子をタップ。
- 原子・線の長押しで小さなメニュー。長押しのまま動かすと原子を移動。
- 2本指で移動・拡大（PC はスクロールで移動、Ctrl/⌘＋スクロールで拡大）。
- 上の帯: 骨格構造式／構造式（H も）の切り替え、元に戻す・やり直す、すべて消す（すぐ消えて5秒間「元に戻す」）。
- 背景: 「選んでから変える」方式は、学生には直感的でなかった（紙に書く動作と違う、ボタンが状況で入れ替わる、状態が見えにくい）。
