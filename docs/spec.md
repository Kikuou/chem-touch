旭川市立大学 共通教養科目「化学」（2027年度〜）向け、スマホで触れる化学学習Webアプリ。

- 作成日: 2026-10-20
- 本書の対象: 実装担当（Claude Code クラウドセッション含む）。本書だけで実装に着手できることを目指す。

## 1. フェーズ④のコンセプト

**「原子から食品・薬まで」**：周期表 → 電子配置 → 結合 → 分子 → 身近な化合物、を一続きにたどれる。

MolView との違い: 作図中心ではなく **「探す・触る・比べる・作る・共有する」** に特化し、スマホのタッチ操作を第一に設計する。

### モジュール構成

| ID | モジュール | 概要 |
|---|---|---|
| A | 3D分子ビューア | 回転・拡大、原子/結合タップ、2D⇔3D連動、官能基ハイライト、2分子比較 |
| B | 化合物ライブラリ | 栄養・看護系の主要化合物を事前収録。検索・カテゴリ・同族体シリーズ |
| C | 分子ビルダー | 組み立てモード（スライダー＋官能基）と自由作図モード |
| D | 共有 | 分子を URL（SMILES）に埋め込み QR で配布 |
| E | 電子配置ビルダー | K/L/M/N 殻モデルで電子を配置。イオン化・結合へつなぐ |
| F | インタラクティブ周期表 | 元素詳細、傾向ヒートマップ、栄養ミネラルフィルター |

## 2. 機能要件

### A. 3D分子ビューア

**表示・操作**
- A-1: 1本指ドラッグで回転、2本指ピンチで拡大縮小、ダブルタップで初期視点に戻る
- A-2: 表示切替: 球棒（既定）／空間充填／棒のみ
- A-3: 水素の表示/非表示切替（既定: 表示）
- A-4: 原子タップ → 元素名・元素記号・（あれば）形式電荷をポップアップ表示
- A-5: 結合タップ → 単結合/二重結合/三重結合/芳香族、結合長（Å）を表示
- A-6: 自動回転のオン/オフ（プロジェクター提示用）

**2D構造式との連動**
- A-7: 2D構造式を3Dと並べて表示（スマホ縦画面では上下、PC横画面では左右）
- A-8: **2D表記は切替式、既定は骨格式**（炭素・水素を省略）。全原子表示（C・H を明示）に切替可能
- A-9: 2Dの原子をタップすると3Dの対応原子がハイライト、逆も同様
  - 実装注意: 2D と 3D の原子インデックスを一致させるため、**3D の molblock（SDF）を唯一の原本とし、そこから 2D 座標を生成**すること（SMILES から別々に生成しない）

**官能基**
- A-10: 官能基を色分けハイライトし、名称ラベルを表示（オン/オフ切替）
- A-11: 対象官能基（SMARTS で判定）: ヒドロキシ基、カルボキシ基、アミノ基、アルデヒド基（ホルミル基）、ケトン（カルボニル基）、エステル結合、エーテル結合、アミド結合（ペプチド結合）、フェノール性ヒドロキシ基、リン酸エステル、チオール、二重結合（C=C）、ベンゼン環
- A-12: 色は官能基ごとに固定し、凡例を表示。色覚多様性に配慮した配色（ラベル併記で色だけに依存しない）

**比較モード**（最重要の差別化機能）
- A-13: 2分子を並べて表示し、**回転・拡大を同期**させる
- A-14: 鏡像体比較では中央に「鏡」を描画し、片方を鏡像として配置
- A-15: 組み込みの比較プリセット:
  - α-D-グルコース vs β-D-グルコース（デンプンとセルロース）
  - オレイン酸 vs エライジン酸（シス/トランス、トランス脂肪酸）
  - L-アラニン vs D-アラニン（鏡像体）
  - ドーパミン vs ノルアドレナリン vs アドレナリン（3分子は切替で2つずつ）
  - エタノール vs ジメチルエーテル（構造異性体）
  - 1-プロパノール vs 2-プロパノール
  - ステアリン酸 vs オレイン酸 vs リノール酸（不飽和度と形）
- A-16: 任意の2分子を選んで比較することも可能

**簡易クイズ（③への布石）**
- A-17: 「この分子の〇〇基をタップせよ」形式。正誤を即時表示。結果は保存しない（③で拡張）

### B. 化合物ライブラリ

- B-1: カテゴリ一覧、キーワード検索（日本語名・英語名・慣用名・分子式。ひらがな/カタカナ揺れを吸収）
- B-2: 化合物カードの項目:
  - 日本語名、英語名、慣用名/別名、分子式、分子量、SMILES、PubChem CID、InChIKey
  - 含まれる官能基（自動判定）
  - **一言解説**（栄養・看護・生活との関わり。1〜3文）
  - 関連化合物（比較・シリーズへのリンク）
- B-3: 同族体シリーズ表示:
  - 炭素数スライダーを動かすと分子が伸び縮みする
  - 沸点・融点・水への溶解性の変化を折れ線グラフで表示（データ出典を明記）
  - シリーズ: アルカン、1-アルカノール、カルボン酸（直鎖）、飽和脂肪酸（C2〜C18）
- B-4: 脂肪酸表示: **n-3／n-6 位置をメチル基末端（ω末端）から色付きで数えて表示**。Δ表記（カルボキシ基側から）との切替
- B-5: データは JSON で管理し、教員がファイル編集で追加・修正できること（§4 参照）

収録化合物は §3。

### C. 分子ビルダー

**組み立てモード**（スマホで直感的に作る。直鎖中心）
- C-1: 炭素数スライダー（1〜18。化学基礎範囲は1〜9、脂肪酸用に18まで）
- C-2: 不飽和結合: 位置を選び、二重結合（シス/トランス選択）・三重結合を追加（複数可）
- C-3: 官能基付与: -OH（位置選択）、-COOH（末端）、-CHO（末端）、C=O（ケトン、位置選択）、-NH₂（位置選択）、メチル分岐（位置選択）
- C-4: 組み立て結果から IUPAC 名（日本語）を表示できると望ましい（直鎖・単純置換の範囲でよい。困難なら名称は省略可）
- C-5: 「作った分子に近い収録化合物」を表示（例: C18・二重結合1個シス9位 → オレイン酸）

**自由作図モード**
- C-6: 原子・結合をタップで描く 2D エディタ（既存ライブラリを組み込む。§6）
- C-7: SMILES 直接入力欄（上級者・教員用）

**共通**
- C-8: 作成した分子をその場で 3D 化（クライアント側で配座生成）し、A のビューアで表示
- C-9: 作成した分子は端末内（localStorage）に「マイ分子」として保存可能

### D. 共有

- D-1: 表示中の分子を共有 URL 化。形式例:
  - 収録化合物: `#/compound/<id>`
  - 任意分子: `#/view?smiles=<URLエンコード>&name=<任意の名前>`
  - 比較: `#/compare?a=<id or smiles>&b=<id or smiles>`
- D-2: 共有 URL から QR コードを生成し、**プロジェクター投影用に大きく表示**するモード
- D-3: 学生も同じ手順で自作分子を共有できる（URL コピー／QR 表示）
- D-4: サーバーは使わない。共有内容は URL のみに含まれる
- D-5: 教員の操作を学生画面に同期する機能はフェーズ①（サーバー）で実装（本フェーズ対象外）

### E. 電子配置ビルダー

- E-1: 対象: 原子番号 1〜20（化学基礎の範囲）。21以降は表示のみ（参考）
- E-2: **既定は電子殻モデル（K・L・M・N 殻）**。同心円の殻に電子を置く UI
  - 元素を選ぶ → 空の殻 → 電子をタップ/ドラッグで配置 → 正誤判定
  - 「おまかせ配置」ボタンで正解をアニメーション表示
- E-3: 価電子数、最外殻電子数、同族元素、貴ガス型配置かどうかを表示
- E-4: 発展モード: オービタル（1s, 2s, 2p…）のボックス表記に切替
- E-5: イオン化アニメーション: 電子を取り去る/加える → 陽イオン/陰イオン、貴ガス型配置との比較
- E-6: 結合への橋渡し:
  - イオン結合: Na → Cl への電子移動アニメーション、NaCl 結晶（3D、ライブラリと共通）へリンク
  - 共有結合: H₂, H₂O, NH₃, CH₄, CO₂ の電子式（ルイス構造）表示。共有電子対・非共有電子対の色分け。3D ビューアへリンク

### F. インタラクティブ周期表

- F-1: 1〜118 番の周期表。スマホでは横スクロール＋ピンチ拡大、またはコンパクト表示（第1〜4周期を主表示）
- F-2: 元素タップ → 詳細: 名称（日・英）、原子番号、原子量、電子配置（E へリンク）、分類（金属/非金属、族名）、身近な用途・体内での役割（主要元素のみ）
- F-3: 傾向ヒートマップ切替: 原子半径、電気陰性度（ポーリング）、第一イオン化エネルギー、（参考）融点
- F-4: **「栄養ミネラル」フィルター**: 主要ミネラル（Na, K, Ca, Mg, P, S, Cl）と微量ミネラル（Fe, Zn, Cu, Mn, I, Se, Cr, Mo, Co）を強調。欠乏症・過剰症・多く含む食品を表示
- F-5: 「人体の元素組成」フィルター（O, C, H, N, Ca, P…）
- F-6: 元素から「その元素を含む収録化合物」一覧へリンク（例: Fe → ヘム）

## 3. 収録化合物リスト

ID は英小文字ケバブケース（例: `alpha-d-glucose`）。立体化学を正確に（特に糖の α/β・D/L、アミノ酸の L、脂肪酸のシス/トランス）。

### 3-1. 化学基礎
H₂O、NH₃、CH₄、CO₂、O₂、N₂、HCl、エチレン、アセチレン、ベンゼン、NaCl 結晶（単位格子）、ダイヤモンド、黒鉛（結晶は小さな断片モデルで可）

### 3-2. 炭化水素・アルコール・カルボン酸（炭素数1〜9）
- アルカン: メタン〜ノナン（直鎖）。異性体例: ブタン/イソブタン、ペンタンの3異性体
- アルケン・アルキン: エチレン、プロペン、1-ブテン、cis-2-ブテン、trans-2-ブテン、アセチレン、プロピン
- アルコール: メタノール〜1-ノナノール（直鎖1級）、2-プロパノール、2-ブタノール、2-メチル-2-プロパノール（1級/2級/3級の比較用）、エチレングリコール、グリセリン
- カルボン酸: ギ酸〜ノナン酸（直鎖）、シュウ酸、乳酸、クエン酸、酢酸エチル（エステル例）
- アルデヒド・ケトン（参考）: ホルムアルデヒド、アセトアルデヒド、アセトン
- エーテル: ジメチルエーテル、ジエチルエーテル

### 3-3. 脂肪酸（栄養学）
| 分類 | 化合物 |
|---|---|
| 短鎖 | 酢酸、プロピオン酸、酪酸 |
| 中鎖 | カプリル酸（C8）、カプリン酸（C10）、ラウリン酸（C12） |
| 長鎖飽和 | ミリスチン酸、パルミチン酸、ステアリン酸 |
| 一価不飽和 | パルミトレイン酸、オレイン酸、エライジン酸（トランス） |
| n-6 系 | リノール酸、γ-リノレン酸、アラキドン酸 |
| n-3 系 | α-リノレン酸、EPA、DHA |

### 3-4. 糖質
α-D-グルコース、β-D-グルコース、D-グルコース（鎖状）、D-フルクトース（β-フラノース）、D-ガラクトース、スクロース、ラクトース、マルトース、アミロース断片（グルコース3〜4量体、α-1,4）、セルロース断片（β-1,4）

### 3-5. 脂質（脂肪酸以外）
トリアシルグリセロール（例: トリオレイン、またはパルミチン酸・オレイン酸・リノール酸の混合型）、コレステロール、ホスファチジルコリン（代表的な分子種）

### 3-6. アミノ酸
タンパク質を構成する20種（L体）。必須アミノ酸9種に印。D-アラニン（比較用）、グルタミン酸ナトリウム、ジペプチド例（グリシルグリシン等、ペプチド結合の説明用）

### 3-7. ビタミン
A（レチノール）、B1（チアミン）、B2（リボフラビン）、B6（ピリドキシン）、B12（※大きいので後回し可）、C（アスコルビン酸）、D3（コレカルシフェロール）、E（α-トコフェロール）、K1（フィロキノン）、葉酸

### 3-8. 食品成分
カフェイン、カテキン（エピガロカテキンガレート）、カプサイシン、β-カロテン、リコペン、アントシアニン（シアニジン）、クエン酸、イノシン酸、グアニル酸、ソルビン酸、安息香酸、アスパルテーム

### 3-9. 生体物質
ATP、尿素、乳酸、ピルビン酸、ヘム、アドレナリン、ノルアドレナリン、ドーパミン、セロトニン、アセチルコリン、ヒスタミン、GABA、コルチゾール、エストラジオール、テストステロン、メラトニン

### 3-10. 医薬品・消毒薬・医療ガス
アスピリン、アセトアミノフェン、イブプロフェン、ペニシリンG、ニトログリセリン、エタノール、イソプロパノール、過酸化水素、次亜塩素酸（HClO）、クロルヘキシジン、O₂、CO₂、N₂O、CO

## 4. データ設計

### 4-1. ファイル構成
```
data/
├── compounds.json      # 化合物メタデータ（全件）
├── sdf/<id>.sdf        # 3D 座標（ビルド時に生成・コミットする）
├── series.json         # 同族体シリーズと物性値（出典付き）
├── comparisons.json    # 比較プリセット
├── functional_groups.json  # 官能基 SMARTS・色・名称
├── elements.json       # 元素データ（周期表・電子配置・ミネラル情報）
└── schedule.json       # 授業回・日付・単元名（ホームの授業帯用。空配列でも動作）
```

### 4-2. compounds.json の1件
```json
{
  "id": "oleic-acid",
  "name_ja": "オレイン酸",
  "name_en": "Oleic acid",
  "aliases": ["cis-9-オクタデセン酸", "C18:1 n-9"],
  "categories": ["fatty-acid", "monounsaturated"],
  "formula": "C18H34O2",
  "mw": 282.47,
  "smiles": "CCCCCCCC/C=C\\CCCCCCCC(=O)O",
  "pubchem_cid": 445639,
  "inchikey": "ZQPPMHVWECSIRJ-KTKRTIGZSA-N",
  "sdf": "sdf/oleic-acid.sdf",
  "sdf_source": "pubchem-3d",
  "note_ja": "オリーブ油に多い一価不飽和脂肪酸。二重結合はシス型で、分子が折れ曲がる。",
  "note_reviewed": false,
  "related": ["elaidic-acid", "stearic-acid", "linoleic-acid"],
  "fatty_acid": { "carbons": 18, "double_bonds": [{ "pos_delta": 9, "geometry": "cis" }], "omega": 9 }
}
```
- `sdf_source`: `pubchem-3d`（PubChem 3D 配座）／`generated`（RDKit 等で生成）
- **`note_reviewed`: 解説文は実装者が下書きし `false` で登録。教員が確認後 `true` にする。** UI では未確認の解説に控えめな印を出す（教員モードのみ表示でもよい）
- 上記の CID・InChIKey は例示。**全件、名称と立体化学を PubChem で照合して記録すること**

### 4-3. データ生成スクリプト
- `scripts/build_compounds.py`（Python、ローカル/CI で実行。本番では動かない）
  1. 化合物の元リスト（`scripts/compound_sources.csv`: id, 日本語名, 英語名, PubChem 検索名 or CID）を読む
  2. PubChem PUG REST で CID・SMILES・InChIKey・分子式・分子量を取得
  3. 3D 配座 SDF を取得。**PubChem に 3D 配座がない化合物**（柔軟すぎる長鎖脂肪酸、トリアシルグリセロール、リン脂質、大きい分子など）は RDKit（ETKDG + MMFF 最適化）で生成し `sdf_source: "generated"` とする
  4. 立体化学の検証: 取得 SMILES の立体記述が意図と一致するか（α/β、シス/トランス、L/D）を確認し、不一致はエラー
  5. `compounds.json` と `sdf/*.sdf` を出力
- 生成物はリポジトリにコミット（実行時に PubChem へアクセスしない）
- PubChem のデータはパブリックドメイン。出典として PubChem をクレジット表示する

### 4-4. 物性値（series.json）
- 沸点・融点・水溶解度は **値ごとに出典（PubChem の該当ページ等）を記録**。出典を確認できない値は入れない（空欄でよい）
- 単位を統一（℃、g/100 mL など）

### 4-5. elements.json
- 1〜118: 記号、日本語名、英語名、原子番号、原子量、族、周期、分類
- 傾向値: 原子半径、電気陰性度（ポーリング）、第一イオン化エネルギー（出典を記録。欠損は null）
- 1〜20 と主要ミネラル: 電子配置、身近な用途・体内での役割（`note_reviewed` 方式で下書き）
- ミネラル: 区分（主要/微量）、主な働き、欠乏症、過剰症、多く含む食品

## 5. 画面構成（スマホ縦画面基準）

```
[ホーム]
```

### 5-1. ホーム画面（決定: ベントー・グリッド＋授業帯）

## 6. 技術構成

| 用途 | 候補（実装時に動作確認して確定） | 備考 |
|---|---|---|
| 3D 表示 | **3Dmol.js** | WebGL、スマホで軽量。BSD-3。`linkViewer` 等で比較の同期を検討 |
| 2D 描画・官能基判定・SMILES 解析 | **RDKit.js**（MinimalLib, WASM） | 骨格式/全原子の描画、SMARTS 判定、2D 座標生成 |
| 3D 配座生成（ビルダーで作った分子） | **OpenChemLib JS**（ConformerGenerator）または RDKit.js | どちらがブラウザで安定して 3D 配座を作れるか検証して選ぶ |
| 2D 自由作図エディタ | OpenChemLib エディタ／JSME／Ketcher のうち **スマホのタッチで最も扱いやすいもの** | ライセンスと容量も比較し、選定理由を README に残す |
| QR 生成 | qrcode-generator 等の軽量ライブラリ | |
| グラフ | Chart.js 等、または SVG 自作 | 同族体シリーズの折れ線のみ |
| フレームワーク | なし（素の HTML/CSS/ES Modules）を基本 | 必要ならビルドツールに Vite を使ってよい |

- 外部ライブラリは**バージョンを固定**し、`vendor/` に同梱（CDN 障害や学内ネットワークの影響を避ける）
- 依存ライブラリとライセンスを README に一覧化
- オフライン対応（PWA / Service Worker）は任意（できれば）。教室の Wi-Fi が混雑しても一度開けば動くと望ましい

## 7. 非機能要件

- **スマホ第一**: タップ領域 44px 以上、縦画面で片手操作できる配置。iPhone Safari と Android Chrome の最新版で動作
- **初回表示**: 4G 回線で概ね 5 秒以内に操作可能。RDKit.js 等の重い WASM は必要な画面で遅延読み込み
- **100 人同時利用**: 静的配信のため特別な対策は不要
- **個人情報を扱わない**: ログイン・アクセス解析・外部送信なし。localStorage はマイ分子と表示設定のみ
- **アクセシビリティ**: 色だけに依存しない（ラベル併記）、ダークモード対応、文字サイズ拡大で崩れない
- **教育的正確さ**: 化合物の立体化学・物性値・解説は出典付き。未確認の解説は `note_reviewed: false`

## 8. 実装マイルストーン（フェーズ④内）

並行開発しやすいよう、**M1〜M3（分子系）と M4（周期表・電子配置）は独立**させる。

| M | 内容 | 完了条件 |
|---|---|---|
| M0 | リポジトリ雛形、ルーティング、下部タブ、GitHub Pages 自動デプロイ（GitHub Actions） | Pages で空の画面がスマホ表示できる |
| M1 | データ生成スクリプト＋ §3-1〜3-4 の化合物、A-1〜A-9（3D/2D 表示・連動・骨格式切替）、B-1〜B-2、D（共有 URL・QR） | グルコースを検索→3D 回転→QR 共有→別端末で同じ分子が開ける |
| M2 | 残りの化合物（§3-5〜3-10）、A-10〜A-17（官能基・比較・簡易クイズ）、B-3〜B-4（シリーズ・脂肪酸表示） | オレイン酸 vs エライジン酸を同期回転で比較できる。DHA の n-3 位置が色表示される |
| M3 | C（組み立て・自由作図・マイ分子）、作った分子の共有 | C18・シス9位の二重結合でオレイン酸を組み立て、3D 表示・共有できる |
| M4 | F（周期表）、E（電子配置）、E-6 の結合アニメーション | Na の電子配置を組み、Cl へ電子を渡して NaCl 結晶へ遷移できる |
| M5 | 教員提示モード、PWA、仕上げ、README（教員向け「化合物の追加方法」を含む） | 授業で1コマ通して使える |

各マイルストーン終了時:
- データ検証スクリプト（全 SMILES がパースできる、全 SDF が存在し原子数が SMILES と一致する、ID 重複なし、必須項目あり）が通る
- スマホ幅（375px）でのスクリーンショット確認（Playwright 等）

## 9. 後続フェーズ（概要）

### ③ 自動生成ドリル（静的・DB不要）
- 数値ランダム化で無限に出題: モル計算、質量パーセント濃度、モル濃度、希釈、pH（強酸・強塩基）、中和、反応式の係数合わせ、化学式・名称
- 誤答ステップの診断（例: 単位換算の誤り、係数比の誤り）
- A-17 の構造クイズを拡張（官能基・異性体・シス/トランス）
- 成績は localStorage のみ。Google Forms の小テストへのリンク集を置ける

### ① ライブ授業（Flask + Render、SQLite 揮発で可）
- 授業コード＋ニックネームで参加（個人情報なし）
- ピア・インストラクション: 個人回答 → グループ議論 → 再回答、前後の分布変化を投影
- 匿名質問ボックス、理解度メーター
- **分子同期モード**: 教員の 3D 視点・表示中の分子を学生画面に反映（短い間隔のポーリングで可）
- Render 無料枠のスリープ対策として授業前に教員がアクセスして起こす運用

### ② 予習記録（Flask + Render + Neon）
- 授業前の確認問題＋「わからなかったこと」記述 → 教員用に誤答傾向・頻出疑問を集計
- 個人情報の扱いは学内規程を確認してから設計（匿名 ID 方式を優先）
