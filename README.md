# ケミタッチ（仮称 / ChemTouch）

旭川市立大学 共通教養科目「化学」向け、スマホで触れる化学学習 Web アプリ。

- 3D 分子ビューア（栄養・看護系の主要化合物を収録、比較・官能基表示）
- 分子ビルダーと URL / QR での共有
- 電子配置ビルダー、インタラクティブ周期表

静的サイト（GitHub Pages）として無料で運用する。ログイン・個人情報なし。
